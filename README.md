# Аналіз продажів Superstore (Power BI Interactive Dashboard)

## Опис проєкту
Цей проєкт присвячений аналізу ефективності продажів роздрібної торгівлі глобального супермаркету за 4 роки. 
Дашборд дозволяє відстежувати ключові бізнес-показники (KPI), виявляти тренди та аналізувати поведінку клієнтів у розрізі регіонів та категорій товарів.


## Основні KPI
* **Total Sales**: Загальна виручка за весь період.
* **YoY Growth**: Темп росту продажів порівняно з минулим роком.
* **AOV (Average Order Value)**: Середній чек замовлення.
* **Total Customers**: Кількість унікальних покупців.
* **Total Orders**: Кількість замовлень.

## Технологічний стек
* **Power Query**: Очищення даних, виправлення форматів дат, видалення дублікатів.
* **DAX**: Створення мір для Time Intelligence (Sales LY, YoY %) та розрахунку середніх показників.
* **Data Modeling**: Створення таблиці-календаря та налаштування зв'язків.

## Ключові інсайти
* Виконано аналіз продажів за кожен рік і визначено приріст в порівняні з минулим роком.
* Візуалізовано географічну концентрацію продажів (Топ-штати: California, New York).
* Виявлено найбільш прибуткові категорії товарів (Technology).
* Виявлено найбільш прибутковий сегмент користувачів (Consumer).
* Визначено топ 5 підкатегорій продуктів за кількістю продажів.
